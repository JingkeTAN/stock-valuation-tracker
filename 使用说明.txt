股票自动化：QDII / ETF 持仓估值跟踪
========================================
完整说明见同目录 README.md。

1. 文件摆放
两个 Python 脚本、gf_ticker_map.csv 和主表放在同一目录。
映射文件相对于脚本位置读取，不依赖终端工作目录。

2. 安装（Python 3.10+）
pip install -r requirements.txt
playwright install chromium

3. 更新持仓
python generate_valuation_sheet.py
输入 Excel 每页三列：名称 / 代码 / 净值权重。
推荐统一小数权重，例如 0.082 代表 8.2%；代码列使用文本。
按提示生成输出，最后选择合并主表。
同名页重建，旧估值按代码恢复；页内历史不迁移。
汇总区下移时自动调整关联单元格公式，历史总账保留。

4. 更新估值（先关闭 Excel）
python update_gf_valuations.py
或：
python update_gf_valuations.py --sheet 399673_创业板50
python update_gf_valuations.py --all
python update_gf_valuations.py --file "权益QDII_ETF_估值相对十年中位.xlsx"

默认权重门槛为 1%，全部持仓使用 --min-weight 0。
--dry-run 不写 Excel，但仍可能采集网页、保存缓存。
--snapshot-only 不抓网页，仅记录表内数据快照。

5. 缓存
gf_cache.json 默认复用 15 天，跨页共享。
需要重新读取时，关闭脚本，手工删除缓存，再重新运行即可。
也可执行 python update_gf_valuations.py --clear-cache，删除后退出。
缓存是股票采集数据，不是组合历史快照。

6. 当前口径
负 EV/FCF 纳入加权、调和和“当一家公司”计算。
EV 当前值不能为零，中位须为正；no_ev=1 时排除。
几何平均只使用正值样本。
PE/PB/PS 当前值或中位不为正时排除。
历史快照上一条不足 100% 的中间记录可能被覆盖，并非每次都追加。

7. 模板更新
代码修改不会自动替换现有 Excel 的旧公式。
通过持仓生成流程重建对应计算页后，再运行估值更新器。
更多参数：python update_gf_valuations.py --help
