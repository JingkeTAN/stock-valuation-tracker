# 股票自动化：QDII / ETF 持仓估值跟踪

导入基金或指数持仓，通过 GuruFocus 更新股票当前估值与历史中位，在 Excel 中比较组合估值并记录快照。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `generate_valuation_sheet.py` | 导入持仓 Excel，生成计算页或合并到主表 |
| `update_gf_valuations.py` | 读取 GuruFocus，更新估值、快照及总览排名 |
| `gf_ticker_map.csv` | 本地代码与 GuruFocus 代码映射，以及指标排除规则 |
| `权益QDII_ETF_估值相对十年中位.xlsx` | 主工作簿 |
| `requirements.txt` | Python 依赖 |
| `使用说明.txt` | 常用命令和维护说明 |
| `gf_cache.json` | 运行时生成的本地采集缓存，不提交到仓库 |

保持两个脚本、映射 CSV 和主表在同一文件夹。生成器按脚本所在位置读取映射，不受终端当前目录影响。更新器优先查找脚本同目录主表，兼容上一级主表，也支持 `--file` 指定。

## 安装

使用 Python 3.10 或更高版本，在项目目录执行：

```bash
pip install -r requirements.txt
playwright install chromium
```

浏览器采集流程还会使用本机 Chrome / Edge；具体浏览器操作以脚本提示为准。

## 更新持仓

自行准备 Excel，每个工作表代表一个组合，第一行是：

| 名称 | 代码 | 净值权重 |
| --- | --- | --- |
| 苹果 | AAPL | 0.0791 |

推荐统一使用小数权重（0.0791 代表 7.91%），或 Excel 原生百分比格式。不要混用裸数字百分数：现有兼容判断只对大于 1.5 的数字除以 100，较小数字有歧义。代码列用文本，避免丢失前导零。该脚本不联网抓取持仓。

运行交互流程：

```bash
python generate_valuation_sheet.py
```

按照提示选择输入表、输出表，最后选择是否合并主表。已有同名页会重建，按股票代码恢复旧估值；页内历史不迁移，中央历史总账保留。汇总区因持仓增加移动时，其他计算页中的关联单元格公式会同步调整，历史总账除外。历史区随汇总区下移，避免重叠。

只生成新工作簿：

```bash
python generate_valuation_sheet.py 持仓输入.xlsx 估值表输出.xlsx
```

命令行模式只生成输出，不自动合并主表。

## 更新估值

先关闭 Excel，并保留一份主表备份：

```bash
python update_gf_valuations.py
```

按菜单选择工作表，按终端提示操作浏览器。指定页面或更新全部：

```bash
python update_gf_valuations.py --sheet 399673_创业板50
python update_gf_valuations.py --all
```

默认处理权重不低于 1% 的股票；使用 `--min-weight 0` 可处理全部持仓。常用参数：

| 参数 | 用途 |
| --- | --- |
| `--file 路径` | 指定主表 |
| `--dry-run` | 不写 Excel；浏览器采集和本地缓存仍可能发生 |
| `--limit 3` | 每页限制处理股票数，便于试跑 |
| `--snapshot-only` | 使用表内数据记快照，不抓网页 |
| `--clear-cache` | 删除本地缓存后退出 |
| `--refresh` | 要求重新抓取 |
| `--help` | 查看完整参数 |

## 缓存和历史

缓存默认复用 15 天，这是项目既定策略。需要重新抓取时，关闭脚本，手动删除 `gf_cache.json`，再重新运行即可。跨组合共享缓存，避免同一股票重复采集。

缓存保存采集到的股票指标；历史总账保存组合快照，两者内容不同。按当前需求，持仓更新时不迁移原计算页历史。采集器会依据覆盖情况补写快照：上一条不足 100% 的中间记录可能被覆盖，完整记录保留。

## 估值口径

- PE、PB、PS：当前值和历史中位均为正才纳入，另受映射排除规则控制。
- EV/FCF：允许负当前值；当前值不能为零，历史中位须为正，且未被 `no_ev` 排除。
- 加权及调和 EV/FCF 纳入有效负值；“当一家公司”按有符号倒数合计。组合倒数合计不为正时，不输出正常的组合相对倍数。
- 几何 EV/FCF 仅用正值样本，并使用该样本权重作为分母，单独标注。
- `skip=1` 跳过股票；`no_pe/no_pb/no_ps/no_ev=1` 排除对应指标。
- 生成器负责公式模板；修改脚本不会自动替换现有主表中的旧公式。需要通过持仓生成流程重建对应计算页后，更新估值。

## 维护

新增股票先检查映射文件，尤其是容易混淆的交易所代码。主表可以保存到 GitHub；浏览器配置、日志、缓存和临时输出保留在本地。README 以当前代码为准。
